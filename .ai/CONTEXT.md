# SYSTEM CONTEXT: CSE323 Customer Ordering System

## 1. THE PRIME DIRECTIVE
Educational vertical slice requiring Test-Driven Prompting (TDP). 
Architecture: Feature-Based Full-Stack Monolith.

## 2. DIRECTORY STRUCTURE
- `src/frontend`: React/Tailwind frontend code for ALL features.
- `src/backend`: API/Business Logic code for ALL features.
- `src/database`: Schemas and database models.

## 3. FEATURE OWNERSHIP (Full-Stack Vertical Slicing)
Every member acts as a Full-Stack Developer for their specific feature.
- **Member A (Khairy):** Core Checkout & Shopping Cart System.
- **Member B:** Menu Browsing & Inventory Catalog.
- **Member C:** Payment Processing & External Gateway.
- **Member D:** Admin Dashboard & Order Management.

## 4. BRANCHING RULES
Formula: `type/feature-task` (e.g., `feature/checkout-react-form`)
