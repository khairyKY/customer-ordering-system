## 🔴 3. Critical Broken Features & Bugs



> [!WARNING]

> These are blocking bugs that require immediate code resolution to allow a clean end-to-end user checkout experience.



1.  **Cart Page `[ PROCEED TO CHECKOUT ]` Button:**

    *   **Symptom:** Clicking the button inside the `/cart` page registers a click but fails to redirect to the `/checkout` route.

    *   **Impact:** Users are stuck on the Cart page unless they manually type the `/checkout` URL.

2.  **Order Submission Payment Failure:**

    *   **Symptom:** Submitting a completed order (via either Credit/Debit or Cash on Delivery) throws a `Payment failed` error dialog.

    *   **Impact:** Blocked final checkout completion.

    *   **Root Cause:** The backend router is missing `/api/payment/process` or returned a `404 Not Found` (see console errors below).

3.  **Admin Orders Detail view read-only:**

    *   **Symptom:** Individual order view does not render interactive buttons or state transition controls despite using the custom `NeonButton` status transitions code.

## 🛠️ 4. Captured Console & Network Errors

|---|---|---|

| `GET http://localhost:3001/api/products` | `ERR_CONNECTION_REFUSED` | Mismatched port configurations initially (now resolved by running Node & FastAPI servers). |

| `PUT http://localhost:3001/api/cart/update` | `400 Bad Request` | Fired during quantity changes. Schema payload mismatches between frontend CartPage and Node.js express backend. |

| `POST http://localhost:3001/api/payment/process` | `404 Not Found` | Payment submission endpoint not registered in Node.js server.js routes. |
