# UI Standardization Sweep
**Objective:** Audit the entire React frontend and replace all raw HTML buttons, inputs, and layout containers with the centralized UI library components.
**Scope:** `App.jsx`, `main.jsx`, and all files in `src/components/`.
**Definition of Done:** Zero raw `<button>`, `<input>`, or generic hardcoded card `<div>` tags exist in the frontend source code outside of the `ui/` directory. The entire app layout must feel cohesive.
